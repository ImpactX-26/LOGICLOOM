# Preview VOLCANO ZERO – LOGICLOOM (with Community Alerts)

1. Extract the ZIP. You get a folder `LOGICLOOM-main-with-community-alerts`.
2. VS Code → File → Open Folder… → select that folder.
3. Install Node.js 18+ from https://nodejs.org if `node -v` fails.
4. Terminal → New Terminal, then:

       npm install
       npm run dev

5. Open the URL printed by Vite (normally http://localhost:5173).
6. Sign in / use "Start Demo" as usual, then click **Community Alerts** in the left sidebar.

Production check: `npm run build` then `npm run preview`.
Standalone feature page (no app): http://localhost:5173/community-alerts/ (keep the trailing slash).
Community Alerts is a SIMULATION: browser audio only, no real sirens or messages.
